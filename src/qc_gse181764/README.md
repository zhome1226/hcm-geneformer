1. `stage_gse181764.py` 核对整数计数、原件摘要、GEO 元数据和各捕获基因轴。两种 feature 空间保留原始顺序；交付使用 37944 个 Ensembl ID 的并集，并附逐捕获可用性掩码。缺测位置的稀疏零填充不能作为观察到的零表达训练目标。
2. `run_gse181764.R` 使用固定成人左心室单核参考的供体分隔训练/留出集进行 SingleR 注释。每捕获全部 ≥500 基因条码进入 scDblFinder，保留高 MT 和 >5000 基因条码；少于 100 个模型条码时明确记为未评分。发布输入缺少正 UMI≤100 的环境池，不重建 EmptyDrops，不宣称新增统计显著的核识别。
3. `calibrate_mixed.py` 用固定参考确定强谱系程序阈值。`finalize_gse181764.py` 按 500≤基因≤5000、MT<5% 的项目基线，结合参考、多标记和共享基因邻域导出核心与待定；仅工具调用及强混合程序同时支持者另存为疑似双细胞。原始计数和全部基因保留；归一化诊断副本明确标注。
4. `verify_gse181764.py` 独立重读全部 9 个原始 MTX，逐值比较交付计数，重算 QC、身份规则和缺测掩码，核对供体/疾病/临床阶段、完整条码审计及文件摘要。通过验收才记完成；严重供体损失与来源局限必须报告。
