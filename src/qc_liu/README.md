# Liu2023 单核计数清洗

输入：Liu et al., Cell Discovery 2023，DOI 10.1038/s41421-022-00490-3；服务器 `validation/liu2023/` 的两个原件。执行目录为 `/home/zhome/xiaoe-internship-data/_processing/all_data_cleaning_20261111/liu2023/`；输出为 `processed/liu2023_qc_20261111/`。原件不修改。

## 运行顺序

作者对象暂存已由`../qc_scp1303/review_preparation/inspect_export_liu.R`完成：只取RNA counts和元数据，导出`liu_RNA_counts.h5`、`author_metadata.tsv.gz`。原tar已在执行目录解压为`snRNA-seq/`；预查会把每个发布矩阵与该计数层逐值比较，不能用integrated或data层替代。

1. `preflight_liu.py`：验证原文件官方大小/MD5，逐值比较13个MTX与作者Seurat RNA counts导出；核实55122核、31944基因、13样本/12供体、MT比例单位，按发布样本保存计数与完整审计。参考基因用唯一匹配symbol，保留主矩阵完整基因轴。
2. `run_liu.R`：成人左心室单核参考SingleR使用固定且供体分开的训练/留出输入；发布样本各自评估。作者已做Scrublet>0.35与混合谱系过滤，因此仅残余混合程序达到≥10核且≥1%严格候选的样本补测scDblFinder；输入该样本全部≥500基因的发布核，含其他细胞类型和>5000基因核。该默认加载量假设不是已知真实残余双细胞率。
3. `review_mixed_liu.py`：评估宽松跨谱系信号；弱单UMI规则在作者已QC核和成人参考中均过于常见，不能当双细胞证据。以固定参考确定强程序阈值max(本类q10,其他类q99)，再要求每谱系至少3个基因各≥2 UMI和双程序比例≥.25。参考阈值并非独立校准的双细胞概率。
4. `finalize_liu.py`：保持500≤基因≤5000、MT<5%的项目严格基线。联合作者CM标签、SingleR、多基因程序与参考尾部/邻域确定核心；身份冲突和强混合程序候选另存待定。只有补测调用与强混合程序共同支持时另存疑似双细胞。保留全基因未归一化X和counts；诊断log1p(CP10k)副本另存并明确标注，不能当原始计数。轻量版≤20k，不复制核。宽松规则attempt1产物存档，不作为最终结果；v2重算决定，可核对数值后复用相同严格候选的诊断几何。
5. `verify_liu.py`：独立重读13个原MTX，对全部交付计数逐值核验；核对完整审计、QC/供体/作者标签、身份规则、参考供体分隔、补测触发、从参考重算的强程序阈值、诊断数值、完整/轻量关系与原/新文件摘要。验收通过才标清洗完成。

长作业用nohup运行`run_preflight.sh`和`run_liu.sh`，保存PID、日志、退出码。恢复前核实原PID及命令是否仍运行；不因观察超时而重复启动。初次预查因服务器EuropePMC连接超时失败，XML在PC公开API下载后上传，历史日志保留；随后真实预查通过后才启动清洗。

## 数据边界

作者元数据Subject把CL0412A/B归为同一健康供体CL0412，应绑定其划分；具体技术/组织重复机制未证实。13个发布矩阵本身已QC，不是完整原始液滴；无法恢复作者删除的核/基因，不重跑EmptyDrops。作者percent.mito是0–1比例，本轮重算为0–100百分数。全31944基因指全部发布基因，不能声称未受作者基因过滤。

疾病标签是来源供体Control=0/HCM=1，非逐核实验病理确证。只有2位健康供体，逐样本/供体和CM1/CM2损失必须报告。参考分数不是概率，疑似双细胞不是实验确证，待定者不强制删为非心肌。跨研究供体重叠和最终训练划分待后续；本轮不进行虚拟细胞模型训练、tokenization、差异表达或靶点排序。

Python复用`_processing/SCP1303_20261111/venv`，R复用`_processing/all_data_cleaning_20261111/r_env`。全部矩阵与逐核表留在服务器；Git仅收代码和文本汇总。
