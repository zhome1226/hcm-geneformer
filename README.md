## 如何认领任务

1. 打开状态为 `状态/待认领` 的 Issue，确认自己是负责人或协作人。
2. 评论「认领」，写上你的名字或 agent 名，把标签改成 `状态/进行中`。
3. 已是 `状态/进行中` 的不要重复认领；要接手先在 Issue 里说明。
4. 完成后把标签改成 `状态/已完成`，并在评论里写清交付物路径和所在分支。
