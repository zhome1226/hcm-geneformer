# HCM 心肌细胞差异表达：结果揭盲前的分析规则

本方案在计算疾病差异前固定；发现与复核为分析角色，不改原细胞的模型训练划分。输入限已 QC 的七套心肌核心；不使用 ToDesk 传输状态决定纳入。每个计数都是基因 × 供体的总和，重复捕获归同一人。

|队列|分析角色|
|---|---|
|SCP1303，15 HCM 对 16 非衰竭（NF）供体|唯一发现队列；全部发现供体不能再作为这个名单的独立检验。|
|Liu2023，10 HCM 对 2 对照|名单哈希锁定后才分析；CL0412A/B 合并；主要评价方向和效应，分别去掉一位对照后报告方向。|
|GSE174691 + GSE161921|室间隔；accession 与疾病完全重合，报告描述性差异，不能分离疾病与来源。|
|GSE138262 完整细胞|HCM 与对照来自不同研究/技术，只报告可共同测量基因的描述性差异。|
|GSE255296、GSE292754|均只有 HCM；分别报告实际检测率和 token 出现率。P186/P194 儿童单列。|

1. SCP 主分析：原始 Cell Ranger 层，edgeR 准似然，TMM 归一化；设计 ~ 年龄（线性、中心化）+ 性别 + 疾病。先查设计满秩。以 HCM 减 NF 定义正负。用 filterByExpr(group=disease, min.count=10, min.total.count=15, large.n=10, min.prop=0.7)，在检验基因全集上 BH 校正。预设 DEG：FDR < 0.05 且 |log2FC| ≥ 0.5（零效应检验后附加观测效应筛选）。
2. 稳定性：相同核心核、相同设计，用作者 CellBender 未缩放计数重复；在主分析中逐一剔除 31 位供体重新拟合。稳健门槛为 CellBender 同向、31 次有效删一均同向，且最小 |删一 log2FC| ≥ 0.25。记录各次效应，删一用于影响诊断，不代替独立复核。另对作者 CM-HHATL 亚型做敏感性检查（≥50 核/供体，两组各≥5 人且能估计），不据其结果重排名。
3. V1 技术门槛：使用实际 2048 序列，至少 8/15 位 HCM 供体各自有 ≥10% 的心肌核包含该 token，并有明确 Ensembl ID / token。原始计数检测率与 token 出现率分别列报。
4. 在满足以上三个门槛的基因中，按主 FDR 升序、|log2FC| 降序、gene_id 升序固定顺序，最多取 200 个。合格不足 100 则如实提交；不以机制基因事后填数、不配额强行平衡方向。完整发现表及每一步人数/基因数保留。候选池中所有基因仅标为 HCM 相关待扰动候选，改善方向待验证。
5. 在读取复核队列表达差异前，写锁定表及 SHA256 和 UTC 时间。Liu 的同向、反向、无法评估分开；两种单对照结果均与发现同向可记为“两位对照分别支持方向”，不称为两次独立重复。未达显著不能解释为与发现矛盾；验证结果不改候选名单。Chin/完整细胞差异无疾病因果解释；其他 HCM-only 资源只报告覆盖。跨研究同人和模型历史未完全排除，不宣称模型独立验证。
6. 本阶段止于候选及证据表。模拟删除需要另定具体 checkpoint 和评价指标；上调、下调均不直接指示有益敲除。
