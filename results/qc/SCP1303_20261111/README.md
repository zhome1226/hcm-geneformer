## 本次实际执行的规则

1. 官方原始 gzip 的 SHA-256 重新核对通过；独立解压到 `_processing/SCP1303_20261111/author_input.h5ad`。输入 592,689 核、36,601 基因、42 位供体、80 个样本，无重复条码及供体诊断冲突。
2. 使用作者 CellBender 未归一化计数计算检测基因数，保留 **500 ≤ n_genes ≤ 5000**；从 `cellranger_raw` 及 13 个 `MT-` 基因重算线粒体百分数，保留 **pct_counts_mt < 5**。
3. 保留 HCM/NF，复用作者 Cardiomyocyte_I/II/III 类型并要求 SubCluster 非缺失；`NF=0, HCM=1`。复用作者已有背景校正和双细胞 QC，保留原分数，本次没有新增双细胞判定。
4. 用 TNNT2、TTN、ACTC1、TNNI3、MYH7 和非心肌谱系标记核验作者群体注释。不要求某一个或所有心肌标记逐核非零；未重新聚类或重注释。
5. `.X` 与 `layers['counts']` 均保存 CellBender 计数；`layers['cellranger_raw']` 保存原始计数。完整保留 36,601 基因和 Ensembl 注释，清除旧降维结果；保存矩阵没有归一化、插补、整合或 HVG 裁切。
6. 固定 seed=20261111，各疾病抽取 10,000 个不同细胞核，尽量均匀覆盖供体；最小 HCM 供体仅有 417 核，全部纳入，其余供体分担余量，没有复制补足。

500～5000 是用户确认的本项目严格基线，不能称为全行业或 HCM 统一标准。Liu 2023 原文采用 300～7000、MT<5%；Chaffin 2022 采用样本/群体动态 QC，并另设低端和线粒体过滤。这里在作者已过滤的对象上增加项目基线。

## 保留率与诊断信息

作者注释且 SubCluster 有效的 HCM/NF 心肌细胞核共 122,362 个，本轮保留 114,927 个。NF 保留 **94.91%**，HCM 保留 **92.85%**；低于 500 基因排除 2,392 个，高于 5,000 排除 5,043 个，本轮没有额外触及 MT≥5% 的目标心肌细胞核。

供体保留率为 **56.05%～100%**。P1735 从 744 核保留 417 核，其余 327 核超过 5,000 基因；高基因数不自动等于双细胞，本次按约定阈值排除，不把它们判成新双细胞。较宽阈值的保留数见 `threshold_sensitivity.tsv`，没有根据分类成绩选择阈值。

全量有 **784** 核出现诊断性混合标记警示，轻量中 **121** 核；另有全量 **245** 核未检测到所选 5 个心肌标记。它们仍按作者注释保留并带 flag：该简易标记比较不能证明双细胞或错误注释，单核掉零也不能据此硬删除。训练前应结合原双细胞分数和群体表达复核，并做包含/排除警示核的敏感性比较。

作者 `cellranger_percent_mito` 实际为 0～1 比例：乘 100 后与重算百分数的中位绝对误差为 0；作者 CellBender 检测基因数与重算值全体一致。详情见 `SOURCE_COMPARISON.json`。

## 划分状态与适用范围

供体划分为暂定 70/15/15，并标记 `provisional_pending_project_ratio`。同一供体的样本全部绑定同一划分；最终微调比例仍需项目确定，不能把本次 split 当成已定稿的训练协议。

Chin、Liu 等候选验证队列未混入，跨研究供体重叠仍待核实。SCP1303 来自左心室、包含终末期心衰 HCM；结果不能直接视为早期 HCM 或室间隔切除队列的代表。
