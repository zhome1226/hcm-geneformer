# 五类质控疑点：如何判断、使用什么工具

日期：2026-11-11。本文件解释拟采用的复核方法；本轮没有新增运行参考注释、聚类、双细胞检测，也没有修改清洗对象或阈值。已执行的检查见REVIEW.md和RECHECK.json。

“心肌细胞身份”与“HCM/NF疾病标签”是两件事：前者通过转录谱判断细胞类型，后者沿用供体临床诊断，不凭某个基因高低重新猜测疾病。双细胞及污染属于技术质量问题，阈值是否过严属于筛选规则问题。

## 1. 这条记录到底是不是心肌细胞

**问题：**作者注释为心肌细胞的记录，是否可能实际为成纤维、内皮、免疫或其他类型？

**证据：**
- 扩展心肌面板与相反谱系面板，观察成套的表达支持，不要求少数基因同时非零。
- 对照已有作者注释，检查这些核在较完整的心脏细胞群体中的邻居和群体表达；UMAP位置只是辅助图示，不能单独定类型。
- 使用来源合适、供体关系可追溯的成人心室单核参考，参考必须包含多种心脏细胞类型，不能只给心肌参考后强制每条记录都分成心肌。

**工具：**Scanpy的点图/热图、基因集评分和邻域检查；SingleR使用外部心脏参考做独立注释。CellTypist或Seurat参考映射是替代路线，使用前必须核实模型是否适合心室单核；默认免疫模型不适用于此任务。

**判读：**多种证据支持心肌，倾向保留；多种证据明确支持另一谱系，考虑排除出心肌对象；参考不匹配或分数模糊时标为待定，不强行贴标签。参考工具预测同样不是实验金标准，也不能用原作者同一批标签训练再自证正确。

## 2. 心肌标记没测到，是掉零、低质量，还是疾病状态

**问题：**某核TNNT2、TTN等未检出，是否因此就不是心肌？

单核测序只捕获RNA的一部分，零值常表示未测到。检测深度、核与整细胞的差异、细胞状态变化，都可能影响标记表达。

**证据：**结合总RNA计数、检测基因数、更多心肌支持基因，以及同群/邻居的整体表达；检查缺失是否集中在某捕获批次、供体或作者亚群。区分“核心心肌程序尚在但少数标记下降”与“整体低复杂度/其他谱系取代”。应激基因不能独立证明心肌身份。

**工具：**Scanpy/Seurat的分组表达图、基因集评分和QC散点图；必要时在分析副本上PCA/邻域/Leiden聚类。计数主对象不因作图而改写。

**本批重点：**轻量75核缺少所选5标记，其中49核仍有扩展面板至少一项支持、26核两套面板均未检出。64/75来自HCM的Cardiomyocyte_III。需检查整个群体与更广表达程序，不能把一个疾病富集群因少数标记低就整群删除。

**判读：**49核不能仅靠额外一个标记确诊，26核也不能只靠表达缺失认定非心肌。必要时保留不确定类别并单独列出原因。

## 3. “混合标记”是不是背景RNA污染

**问题：**一条记录同时带心肌和非心肌RNA，是背景污染、误标还是两个核混入？

121个警示来自本项目自定义的小面板比较，不是公认的身份分类阈值或正式双细胞判定。不同面板大小、基因选择和测序深度均会影响该比较，不能把121当作已确认的污染数量。

**证据：**看相反谱系是否仅有少量零散转录本，还是一组相关基因协调表达；比较Cell Ranger与CellBender计数，看异谱系信号是否随着背景校正减弱，同时参考群体、邻域和双细胞评分。校正前后差异本身也不能证明污染原因。

**工具：**现有成对计数层配合Scanpy图表；CellBender/SoupX是背景建模工具。本数据已经CellBender校正，先检查已有结果。重新可靠估计空液滴背景需要合适的原始液滴/背景信息，不能仅凭已过滤矩阵假称完整重建背景。

**判读：**少量异谱系RNA而核心心肌程序清晰，可能只是背景；两套完整谱系同时明显，则提高对双细胞或误标的怀疑，转入第4项。单个COL1A1或PTPRC阳性不作为立即删除理由。

## 4. 是否存在作者处理后仍漏检的双细胞

**问题：**同一barcode是否实际记录了两个细胞核？计算机过滤不会新造物理双细胞，这里“新双细胞”准确说是重新发现的疑似漏检记录。

**证据：**先复核作者Scrublet分数在原样本/群体中的位置；再结合总计数/基因数异常、混合谱系程序和邻域。若有必要且输入合适，用另一方法提供补充证据。

**工具：**已有Scrublet评分；必要时以scDblFinder做补充，或按正确输入复核Scanpy Scrublet。双细胞检测应尊重实际捕获批次，并利用相应批次较完整的细胞类型构成，不能只拿185个警示核或2万抽样心肌核跑一个全局模型。当前对象已经作者过滤，重跑的结果不能假称与最初未过滤数据上的检测等价。

**限制：**评分0.16不能直接解释成已证实16%污染；评分前5%也不等于这5%都是双细胞。不同类型形成的双细胞通常更易识别，同型双细胞更难仅凭表达区分。缺乏合适的cell hashing、基因型等实验信息时，不保证逐核完全定论。

**判读：**工具判定、跨谱系表达与计数等证据共同支持，才考虑排除；工具之间冲突则标待定。不会因为单一自定义面板分数或UMAP桥接位置就删除。

## 5. 5000基因上限是否对某位供体过严

**问题：**筛掉的细胞是真的质量差，还是它们本来检测更深、RNA更多？这是规则适用性问题，并不是“供体身份有错”。

**本批重点：**P1735原744个目标心肌核，327个超过5000，保留417个。44%的损失提示应审查，但不能据此证明阈值一定错误。

**证据：**把这327核与该供体保留核、其他供体同类心肌核比较：检测基因数/总计数分布，线粒体比例，双细胞评分，表达复杂度及谱系一致性。看是否形成平滑的高深度尾部，还是独立的异常群体。

**工具：**Scanpy/Seurat的按样本/细胞类型QC图，分布与稳健离群值诊断；现有阈值敏感性表已含5000/6000/无固定上限的保留数。下一步还需比较不同规则新增保留的核是否具有合理表达质量。

**判读：**若多数被删核仍有清晰心肌程序、无其他异常，应考虑上限是否过严；若有双细胞/混合表达等联合证据，支持继续排除。不得仅为凑够数量、让两组保留率相同，或提高分类准确率来改阈值。

任何合理调整都应作为明确的新版本，保留原500～5000严格基线和两套差异；一旦放宽到6000，就不能仍声称该新版本严格满足5000上限。规则需在各疾病组一致适用，不能只为某个HCM供体放行。

## 对本项目建议的顺序与产物

1. 用作者较完整的心脏细胞对象及分析副本，为185个轻量警示核及对应完整对象核补充成套标记、邻域和捕获批次证据；特别关注Cardiomyocyte_III、两套面板均无支持的26核。
2. 选用合适成人心室参考，做一次独立注释并保留不确定结果；如还有双细胞证据冲突，再有针对性补充scDblFinder，而不是先盲目重跑全部处理。
3. 同时审查P1735被5000上限排除的327核，比较固定基线与候选上限的质量，依据技术证据决定是否提出新版本。

交付应为逐核“保留/排除/待定”及理由、采用工具和参数、供体/疾病保留率、严格基线与追加复核版本的差异。尚未完成上述分析；本文件不将方法建议冒充新的运行结果。
