# SCP1303微调数据复核策略 v0.1

制定日期：2026-11-11。执行状态更新：第一步候选登记与初步证据已完成，工具环境和参考下载已准备；见 `preparation/READINESS.md` 与 `preparation/INITIAL_EVIDENCE.md`。尚未执行本策略的新参考注释、真实数据聚类、双细胞调用或阈值调整。

## 目标与范围

为Geneformer的HCM/NF心肌状态微调准备可追溯的数据：排除有充分证据的技术混杂，同时保留可信的疾病状态和供体覆盖。当前只处理SCP1303，外部验证队列清洗、tokenization、模型训练及靶点排序不在本轮执行范围。

采用“定向复核 → 记录证据与判定 → 固定规则 → 导出新版本”的顺序。当前500～5000基因、MT<5%的严格对象作为基线保留，所有新版本保留原始barcode和来源。

## 第一步：建立证据表和对照范围

从作者工作对象、完整清洗对象及逐核审计表生成统一记录，固定输入哈希、脚本版本和seed=20261111。字段至少包括barcode、donor_id、capture/sample_id、原疾病、作者类型/SubCluster、计数、基因数、两套MT指标、原双细胞分数及已有警示。

记录轻量成员、完整成员、高基因数排除状态及每种警示来源。把疾病标签作为诊断来源和分层报告字段，不用疾病预测分数反过来决定细胞是否合格。

复核上下文应包括同捕获批次的其他细胞类型，以及各供体/作者心肌亚群中未报警的对照核。作者CM_III整群须共同查看。不得只拿185核做聚类、参考比较或双细胞建模；未报警不自动等于金标准，若对照检查发现新问题，应记录理由并扩充复核清单。

**产物：**逐核候选登记表、按供体/样本/亚群的数量概览、可追溯的对照核选择记录。

## 第二步：身份、标记缺失和背景混合联合复核

使用现有Scanpy环境，在分析副本上开展：

1. 观察扩展心肌及成纤维、内皮、免疫等多谱系程序，绘制分组点图/热图和质量指标分布。综合程序比某一个基因非零更有意义；自定义小面板分数仍只作诊断。
2. 检查邻域和群体支持、各捕获批次的一致性，结合原作者类型/SubCluster。必要时在包含足够对照类型的副本上做PCA/邻域/聚类，UMAP仅辅助展示。分析副本的归一化不覆盖交付计数。
3. 比较同一核Cell Ranger和CellBender计数中的异谱系信号。零散背景且核心心肌程序清晰者允许保留；无充分原始液滴信息时不重复运行完整背景估计，也不把计数差异直接认定为污染证明。
4. 做一次独立参考注释，首选SingleR配合经过核查的成人心室单核参考。执行前必须记录参考的来源、版本、组织/技术、标签集合及供体关系；参考包含多种心脏细胞类型，不能仅提供心肌类或直接用原作者同一批标签自证正确。Chin/Liu等预定最终验证队列不默认用作本轮参考。
5. 参考适配和可分性需先检查；分数差距/拒判规则依据所选工具和参考的校准确定并记录，不临时编造通用0.8置信度。参考不适配或证据冲突者标待定，不能强制分成某类。

**停止扩展工具的条件：**整体谱系、作者群体和适用参考证据已一致，且没有实质双细胞疑点，即可作出对应判定；无需再增加第三、第四种注释器。

**产物：**每核身份结论、参考适配记录、核心证据图，及26个重点核和CM_III群体的解释。

## 第三步：只对仍有实质疑点的捕获批次补充双细胞复核

首先解释作者Scrublet分数在相应样本/群体中的位置。高分、两套完整谱系并存、计数异常等证据共同存在，或身份证据与原评分持续冲突时，再触发补充工具。

补充工具首选scDblFinder，按真实捕获批次使用该批较完整的细胞类型构成和适当未归一化计数。实际输入已由作者过滤，新的调用不能宣称重建了最初未过滤液滴上的检测。明确记录输入层、预期率依据、阈值和随机种子；没有实验加载信息时报告预期率假设。

评分0.16、前5%排名、基因数高或UMAP位于群体之间，都不能单独作为删除规则。特别是同型双细胞，允许保留无法确定的状态，不承诺消除所有漏检。

**产物：**按捕获批次的复核记录；有充分支持的疑似双细胞判定及理由，或保留/待定依据。

## 第四步：审查5000上限，先看P1735再检查全体一致性

先比较P1735的327个被排除核与其417个保留核，并参照其他供体同类心肌核。检查总计数/基因数、MT、复杂度、作者双细胞分数、原有熵/外显子指标以及谱系支持，区分深度较高的连续分布与联合质量异常。

随后对全体高基因数候选做同样的概览检查，确认结论不是P1735特例。第一轮仅比较5000与6000两个固定上限；无固定上限仅用作诊断参照。基因下限500与MT<5%本轮保持作为既定条件，减少同时改变参数。

- 若高基因数候选有明显混合谱系/双细胞或其他质量异常，支持继续排除相应核。
- 若较高基因数核有清晰心肌程序且其他质量指标合理，可提出采用6000等有依据上限的新版本，并对所有疾病组一致应用。
- 若证据不足，保留5000严格基线，把高端候选登记为待定，不为补齐数量自动放行。

任何上限调整需先形成书面理由和各供体/亚群影响表，再固定新规则；不得依据分类准确率或最终测试集表现决定上限。

**产物：**高基因数候选复核表、5000/6000差异表及明确的“维持上限/建议调整/证据不足”结论。

## 第五步：作出逐核决策，冻结规则后导出

| 结论 | 判据 | 处理 |
| --- | --- | --- |
| 保留 | 总体质量合格，心肌程序及其他证据支持；少数标记缺失或轻背景可以接受 | 纳入符合相应版本阈值的主对象 |
| 排除：非心肌 | 整体程序和适用参考等证据一致支持其他类型 | 从心肌主对象排除，记录类型及理由 |
| 排除：双细胞 | 合适方法的调用与混合谱系/其他证据共同支持 | 排除并保留证据，不称作实验确证 |
| 排除：低质量 | 联合质量指标支持记录缺乏可靠表达信息 | 排除并注明依据，不用缺单一标记替代质量判断 |
| 待定 | 证据不足、参考不适配或方法冲突 | 单独保留；可暂缓纳入首轮核心微调，报告疾病/供体/亚群覆盖损失 |

细胞身份判断与版本阈值资格分开记录：例如一个6000基因核可以有可信心肌身份，但不符合原5000严格基线。不会在原版本中悄悄改变规则。

如果待定集中在HCM CM_III等群体，应优先解决群体问题，不能单靠删掉该群来获得更好分数。判据中“多个证据”不是任意软件票数多数决；关联的工具/面板不作为完全独立证据重复计票。

拟交付（文件名为计划，尚未生成）：

- `review_summary.tsv`：按疾病/供体/样本/亚群汇总。
- `qc_policy.json`：冻结的规则、版本及证据来源。
- 新目录下的完整与轻量AnnData、校验和及验收报告。

轻量仍以约20000核为目标，按疾病与供体分配，固定随机种子；在供体内检查可信心肌亚群覆盖。避免复制细胞或强行把HCM/NF亚群比例调成一致；若补抽替换被排除核，应保存替换记录。

## 验收与本轮完成标准

- 原严格对象保留；所有185个轻量警示及完整对应987个警示有可追溯处理结果，高基因数候选有一致处理规则或明确待定状态。
- 新对象符合其声明的阈值、计数来源与标签定义，未归一化计数及全基因空间保留；重新验证计数、条码、疾病映射和哈希。
- 报告31位供体及心肌亚群覆盖变化。若某供体/群体因可靠质量证据无法保留，应如实报告并处理代表性问题，不靠放宽规则强保留。
- 待定数量无需硬清零，但每项有理由。任何集中于疾病/供体/亚群的选择损失须写明。
- 导出版本不等于已经确认模型可用性。正式微调前仍需确定最终供体划分；目前70/15/15只是暂定。

## 后续训练阶段再做的敏感性比较

固定供体划分、可比训练设置和评价集，比较经复核主对象与纳入待定核的版本。报告样本量/供体/亚群组成差异，避免将补抽变化当作质量效应。观察未见供体上的分类表现以及候选靶点排序稳定性，不按最高AUC反向选择QC。最终测试集不参与反复选择规则。

这一阶段在本轮QC策略之外；当前无需先运行多个完整模型才能判断阈值实施是否正确。
