# HCM差异表达与Geneformer V1模拟敲除候选策略

日期：2026-11-14（北京时间）。策略已归档，第一轮供体和计数检查已完成，详见[检查报告](../results/target_discovery/preflight_20261114/PREFLIGHT_REPORT.md)。尚未运行DGE、训练或扰动，尚未产出候选基因名单。

## 结论

以差异表达分析（DGE）建立候选池，再逐基因进行Geneformer模拟删除，方向合理。
差异表达是关联证据；显著、上调、致病、可通过敲除改善疾病，是不同命题。
建议目标为100–200个有证据分层的待测试候选，另设对照；数量为项目规模，不是统计学标准。
不为凑满100个而调整显著性阈值，也不把文献候选标成显著差异基因。

## 先明确模拟问题

本方案暂按“在HCM心肌细胞中删除某基因，是否使模型表示向非衰竭/对照状态移动”设计。
若研究目的变成“在对照细胞中敲除以诱发HCM”，起点、目标状态及候选优先级需重新定义。
SCP1303的NF应表述为非衰竭供体对照，不能仅凭标签称其为完全健康人。
MYBPC3功能不足可导致HCM；不能因为它是HCM相关基因，就默认敲除会改善疾病。[4]

## DGE输入与统计

- 使用QC后、tokenize前AnnData .h5ad内经过核实的原始整数counts；不使用Arrow token序列、整合表达、缩放值或log值作为计数模型输入。
- SCP1303实际X/counts是作者CellBender校正计数，原始计数保存在cellranger_raw层；拟以前者作敏感性比较、后者作原始计数主分析，DGE前固定方案，不改既有token输入。
- 按供体汇总同一类可比心肌细胞的counts，形成pseudobulk，再用edgeR准似然或DESeq2比较HCM与对照。
- 同一供体多个样本不能充当独立生物学重复；几十万个细胞不能代替足够多的供体。[1]
- 检查组织部位、年龄、性别、平台、疾病严重程度等可用变量；仅在样本量和设计矩阵允许时纳入协变量。
- 处理心肌细胞亚型组成：用预定义、可比较的亚型做分层或敏感性分析，避免把疾病反应状态本身作为必须消除的因素。
- 可预设探索性筛选起点为BH-FDR<0.05且|log2FC|≥0.5（约1.41倍）；这不是行业强制阈值，须在看结果前确定，并报告效应量、不确定性、表达覆盖及供体一致性。
- 低表达过滤使用适合pseudobulk设计的规则；具体参数随供体数和测序深度预先确定，不能根据是否凑够100个反复改变。

## 现有四套数据的初步定位

| 数据 | 建议用途与限制 |
|---|---|
| SCP1303 | 同一研究有HCM与NF，拟作主要发现来源；先核对实际保留的供体数、部位、重复及模型既往接触情况。 |
| Liu2023 | 原设计10 HCM+2健康，拟作独立方向验证；清洗后供体保留情况仍需查元数据。对照供体少，不能因未达显著就断言未复现。 |
| GSE174691 + GSE161921 | 分别为HCM和供体对照，accession与疾病完全关联；需核对实验可比性，只能暂作支持性证据，不能靠普通批次校正保证疾病效应可辨识。 |

这些是设计建议；第一轮只读检查已确认研究内供体数与计数层，跨研究供体独立性尚未证实，未改动分组。
先划定发现与独立验证供体，再做候选发现；验证数据不能同时参与筛选和宣称独立验证。
核查跨研究供体重复、与原Geneformer预训练/微调材料的重叠，记录可声称的独立性范围。
原Geneformer论文的心肌病微调已使用Chaffin来源队列；若采用其疾病微调权重，不能将同来源SCP1303自动视为全新外部验证。预训练语料交集仍需另核查。

## 候选池组成

1. 差异表达支持：效应稳定、供体间方向相对一致的基因；优先记录独立研究支持程度，不只按P值排序。
2. 机制/文献支持：HCM相关调控因子和通路节点可补充，即使不是显著DEG，也必须如实标注证据来源。
3. 干预方向审查：上调可能是有害驱动，也可能是保护性代偿；下调不能自动推断适合继续敲除。疾病基因身份不等于治疗敲除靶点。
4. 技术可测性：Ensembl映射明确、属于V1词表，并在足够数量的HCM细胞实际2048-token输入中出现；报告跨供体覆盖度。
5. 设置独立对照：表达/序列出现率匹配的背景基因及有明确方向依据的机制对照；不得把所有已知疾病基因当成“改善型阳性对照”。

若合格DEG不足100，保留真实数量；可通过预先定义的文献/调控证据扩展总候选池并分层，不能声称已获得100个显著DEG。

## Geneformer模拟与解释

- 当前仅完成V1编码，尚未完成本项目模型训练。先确定V1预训练基线及是否进行疾病任务微调，按供体留出评估，避免细胞随机拆分泄漏。
- DGE发现用.h5ad，扰动用已有.dataset。二者通过Ensembl ID连接，不需要为DGE重新tokenize。
- 官方delete操作从rank-value序列删除基因，输出embedding变化；它不直接预测敲除后的完整表达矩阵、细胞存活或临床疗效。[2]
- 首轮逐个删除候选。官方当前文档说明genes_to_perturb传入多基因列表会测试共同扰动；实现时核对本项目固定版本，不能将100个基因列表误当100次独立敲除。[2]
- 使用匹配V1的模型、词表、2048长度及无CLS的表示配置，不能照搬最新文档默认V2/CLS。
- 评价HCM向对照参照的状态移动，并比较背景扰动；按供体汇总结果和不确定性，校正多重比较，检查留出供体/独立队列的一致性。
- 某基因未进入某细胞输入序列，不能把该细胞的“无变化”解释成该基因没有生物学作用。
- “更像对照”的模型输出只是待验证假设；还需保留心肌身份、评估必要基因风险，并由真实扰动证据检验。Geneformer原论文提供了心肌病状态模拟及部分实验验证的先例，但不保证新HCM候选成立。[3]
